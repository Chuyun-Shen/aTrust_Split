# 验证记录

2026-11-04 · **0.1 experimental / 源码预览**

## 已验证

- macOS ARM64、Python 3.13：46 项单元及本机回环测试通过。
- 默认单 aTrust 配置不需要容器或 tun2socks；正常退出、路由失败及原生会话变化均进入恢复流程（mock 验证，无真实路由改动）。
- 配置拒绝宽泛/冲突 IP；路由变更前写 journal，恢复检查归属、接口与启动身份。
- 容器 SOCKS 拒绝非白名单/域名/UDP，并验证 TCP 半关闭转发；Linux 网卡绑定顺序由 mock 验证。
- 默认与双机构示例的 CLI 配置、计划、Clash 片段检查。
- 原开源准备中，使用固定 ARM64 基础镜像的无网络短时容器读取启动脚本，精确修补与 shell 语法检查通过；未启动 aTrust。

## 仍需实机验收

- 当前开源版本的单 aTrust / Clash 系统代理及 TUN 模式下的业务访问与恢复。
- 可选容器镜像完整构建、双机构认证、Linux 实际接口绑定及透明 TCP 传输。
- 原生会话切换、睡眠唤醒、异常退出后的真实恢复；Intel Mac 与其他 aTrust 版本。
- GitHub CI 结果以仓库 Actions 为准。本地通过不等于远端通过。

验收需同时检查内网业务、原有 Clash 网站、实际路由与停止恢复。不能用单元测试或 TCP 端口可达代替双账号业务验收。当前个人 VPN 未切换为此开源实现。

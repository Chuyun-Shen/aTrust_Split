## 桌面版 1.4.0 · 2026-11-04

- macOS ARM64、Python 3.13.5：桌面版 107 项测试通过；原 CLI 46 项测试及两份示例配置检查通过。
- 实际构建 PyInstaller 后台与 Swift 菜单栏应用，ad-hoc 签名校验通过；打包程序 `--help`、隔离 HOME 的连接查询及 Swift `--self-test` 通过。
- `--ui-smoke` 实例化真实菜单控件，以合成数据检查四种勾选组合及两种本机偏好；不启动登录辅助、通知或连接服务。未执行真实登录界面交互。
- 隔离临时配置运行 CLI：全部断开 → A → A+B → B 本机/A 容器 → B → 全部断开，选择持久化且文件权限为 `0600`。
- 本机回环 SOCKS5 握手与 SSH 标识探测通过，不连接外部业务服务器。
- 修复前以隔离替身复现过期取消选择注销新会话、offline 被误判为注销完成、DNS 监听失败残留半初始化、虚拟地址变化时遗漏恢复，以及安装器跟随用户符号链接写入。修复后由对应行为回归覆盖；没有改动真实路由或 launchd。
- 公开版只包含机构 A/B 的保留域名示例；实际机构及业务端点由本机 JSON 配置提供。个人配置、日志、诊断捕获、备份、客户端和本机构建产物不纳入发布。

本次未安装后台、切换现有 VPN 或修改 SSH/Clash 配置；未验证容器完整构建、真实机构认证、双连接业务、真实路由恢复、睡眠唤醒或其他客户端版本。桌面版目前只提供 Apple Silicon 构建；SOCKS 的 loopback 端口不提供多用户隔离。

## CLI 0.1 experimental · 2026-11-04

## 已验证

- macOS ARM64、Python 3.13：46 项单元及本机回环测试通过。
- 默认单 aTrust 配置不需要容器或 tun2socks；正常退出、路由失败及原生会话变化均进入恢复流程（mock 验证，无真实路由改动）。
- 配置拒绝宽泛/冲突 IP；路由变更前写 journal，恢复检查归属、接口与启动身份。
- 容器 SOCKS 拒绝非白名单/域名/UDP，并验证 TCP 半关闭转发；Linux 网卡绑定顺序由 mock 验证。
- 默认与双机构示例的 CLI 配置、计划、Clash 片段检查。
- 原开源准备中，使用固定 ARM64 基础镜像的无网络短时容器读取启动脚本，精确修补与 shell 语法检查通过；未启动 aTrust。
